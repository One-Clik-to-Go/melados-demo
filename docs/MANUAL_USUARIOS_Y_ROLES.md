# Manual de Gestión de Usuarios, Permisos y Simulador SuperAdmin

Este manual describe el sistema de roles de usuario y la herramienta de simulación en vivo para administradores en la plataforma **Pro Niñez Panamá**.

---

## 1. Roles del Sistema

| Rol | Descripción | Permisos |
| :--- | :--- | :--- |
| `EVALUADOR` | Aplicador de campo de pruebas | Ingesta de evaluaciones EGRA/EGMA y acceso al portal móvil |
| `ADMIN` | Administrador general de cohorte | Alta de escuelas, evaluadores, cohorte y resolución Ley 285 |
| `REPORTE / AUDITOR` | Consultor o entidad financiadora | Acceso a indicadores de impacto longitudinal sin permisos de edición |

---

## 2. Simulador de Roles SuperAdmin

El usuario con credenciales de **SuperAdmin** (`andres@grupoplustech.com`) cuenta con un selector especial en la cabecera que le permite probar en vivo la vista de cualquiera de los roles (`ADMIN`, `EVALUADOR`, `REPORTE / AUDITOR`) sin cerrar sesión ni alterar la autenticación del usuario.
